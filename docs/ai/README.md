# AI-сервис: первый этап

Используется существующая синхронная функция
`recommend_contractors(order: SearchRequest, candidates: list[Contractor]) -> list[Recommendation]`
из `Backend/ai_service.py`. Каждый результат содержит `contractor` и `reason`.
Backend передаёт уже отфильтрованных кандидатов. HTTP-контракт не изменён.

## Включить mock

Из корня проекта в PowerShell перед запуском backend:

```powershell
$env:PYTHONCASEOK = "1"
$env:AI_MODE = "mock"
python -m uvicorn backend.main:app --reload
```

Также можно указать `AI_MODE=mock` в локальном `.env`: существующий backend
загружает его при запуске. Прямой импорт AI-сервиса сам `.env` не загружает.
При смене режима перезапустите backend. Переменная окружения имеет приоритет
над значением из `.env` при существующей настройке загрузки.

Mock не требует `OPENAI_API_KEY` и `OPENAI_MODEL`, не создаёт HTTP-клиент
и не выполняет сетевых запросов. Возвращает первых трёх уникальных по ID
подрядчиков в порядке входного списка (или меньше, если их недостаточно).
Пустой вход возвращает `[]`. Исходный заказ и кандидаты не изменяются.
Каждое объяснение содержит `[MOCK — тестовый ответ]`. Это заглушка для проверки
интеграции, а не ранжирование или оценка качества подрядчиков.

## Offline-тесты

Используйте окружение проекта с установленными зависимостями из `requirements.txt`:

```powershell
$env:PYTHONCASEOK = "1"
python -m unittest discover -s tests -p "test_ai_service.py" -v
```

Тесты используют искусственные профили, изолируют переменные окружения
и подменяют HTTP-клиент. Настоящих API-вызовов нет; ключи не нужны.
Проверяются размеры результата, уникальность ID, отметка mock, неизменность
входа и сохранение режима OpenAI по умолчанию.

## Вернуться к OpenAI

```powershell
$env:AI_MODE = "openai"
```

Настройте `OPENAI_API_KEY` и `OPENAI_MODEL` в своём окружении и перезапустите
backend. Значение по умолчанию при отсутствии `AI_MODE` — `openai`.
Отсутствие ключа или модели не включает mock. Неизвестный режим для непустого
списка вызывает `AIServiceError` с кодом 503; пустой список всегда даёт `[]`.
Существующие промпты, вызов через `httpx` и обработка ошибок OpenAI сохранены.

Ограничение существующего проекта: каталог называется `Backend`, а импорты
используют `backend`. Это мешает обычному импорту, в том числе в проверенном Python на Windows. В командах выше временно включён `PYTHONCASEOK=1` для Windows; это не переносимое решение для Linux;
переименование не входит в данный этап.
