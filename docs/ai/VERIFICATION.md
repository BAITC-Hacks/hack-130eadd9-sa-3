## Проверка настоящего каталога

Использованы неизменённые `load_contractors` и `filter_contractors`, 66 профилей.

- Категория «Ведущий»: 15 профилей; spy с `wraps` подтвердил, что **все 15**
  дошли до настоящей AI-функции. В модельный запрос вошли только выбранные три.
- «Флорист», Астана: 1 профиль; Алматы: 2. Тройка не дополняется.
- «Флорист», город «Зарубежье»: нет этой категории в существующем городе.
- `max_price_kzt=0`: нет кандидатов по условиям. Обе пустые выдачи — без API.
- «Ведущий», Алматы, 2026-09-23 / 2026-09-24: наборы различаются по исходному
  `busy_dates`. HK-44733 занят 23-го и свободен по каталогу 24-го; занятые не
  достигают рекомендаций. Выбранная дата сохраняется в evidence.
- «Фотограф», пожелание «Документальная фотография»: HK-61323 поднимается за
  документальный фотожурнализм в описании, а не за имя или рекламный рейтинг.

Ошибки основного backend, блокирующие эти сценарии, не обнаружены. Его прежнее
правило исключать пустой `max_hours` при фильтре длительности оставлено как есть.

## Исправленные дефекты и ход проверки

1. Неверный регистр импортов: исправлен `backend` → `Backend`, обход PYTHONCASEOK удалён из инструкций.
2. Первый прогон старых тестов после изменения транспорта не подменял AsyncClient:
   были сетевые попытки с фиктивными тестовыми значениями, завершившиеся ошибкой
   соединения в ограниченной среде. Это не live-проверка и не успешный OpenAI.
   Теперь перехватывается правильный транспорт; отдельно проверяется, что
   неподменённый исходящий HTTP блокируется даже при ошибке тестовой подмены.
3. Первоначальный запрет socket.connect мешал внутренней Windows socketpair
   для asyncio. Он заменён запретом внешнего HTTP-транспорта, сохранив offline-изоляцию.
4. Старые ожидания временного сбоя 504/429 заменены проверкой нового согласованного
   fallback, а успешные фикстуры дополнены обязательными внутренними evidence_refs.
   Проверки неверных ID/схемы и основных backend-функций сохранены.
5. Короткое пожелание «Репортаж» не учитывалось из-за ограничения длины цитаты:
   отделено чтение пожеланий от отбора цитат профиля.
6. Исправлены ложные противоречия: «час» внутри «частных»/«счастливым»;
   «городской»/«вид на город и горы» как указание другого города;
   «казахская кухня» как обещание языка. Добавлена регрессия по всем 66 профилям.
7. Вместо общего вводного текста при возможности выбирается конкретная цитата
   о стиле/услуге; длина текста не влияет на рейтинг.
8. Для нового процесса на Windows тест сохраняет SYSTEMROOT/WINDIR, но очищает
   секреты и настройки: иначе импорт asyncio давал WinError 10106.

После этих исправлений весь набор повторно прошёл. Неисправленных FAIL в
перечисленных offline-критериях нет. Недоступные внешние проверки обозначены NOT RUN.

`model_configured=False` (значения не читались в вывод). Ранее присланный в чат
